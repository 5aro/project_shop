# 참고 자료

수업별 원문 링크는 [대응표](CURRICULUM_MAP.md)에 있습니다. 다음 공식 자료를 구현 버전과 개념 확인에 사용했습니다.

- [Airflow 3.3.1 시작하기](https://airflow.apache.org/docs/apache-airflow/3.3.1/start.html): standalone과 로컬 실행.
- [Airflow DAG](https://airflow.apache.org/docs/apache-airflow/3.3.1/core-concepts/dags.html): DAG와 실행 구조.
- [Polars streaming](https://docs.pola.rs/user-guide/concepts/streaming/): lazy 실행과 streaming engine.
- [pgvector](https://github.com/pgvector/pgvector): 벡터 연산자, HNSW, IVFFlat.
- [MiniLM 모델 카드](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2): 다국어 384차원 임베딩.
- [MongoDB 8.0 릴리스 안내](https://www.mongodb.com/docs/manual/release-notes/8.0/): Linux 커널 호환성 제한.

수업 원문 저작물은 프로젝트에 복사하지 않았습니다. 합성 데이터·실험 결과는 이 프로젝트에서 생성했습니다. 임베딩 모델과 라이브러리는 각 배포처의 라이선스를 따릅니다.
