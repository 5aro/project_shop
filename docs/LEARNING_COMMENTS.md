# 학습 주석 읽기 안내

이 프로젝트는 합성 데이터로 수집·검증·적재·분석을 실습합니다. 코드의 동작을 바꾸지 않고 함수의 계약, 주요 단계, 구현 이유를 한국어 주석으로 설명했습니다. `source.py`와 같은 방식으로 코드 블록 앞에 상세 설명을 보완했습니다. 입력·출력, 변수 의미, Python/SQL/JavaScript 문법, 구체적인 작은 예시와 실패 조건을 해당 코드 바로 위에서 확인할 수 있습니다. 먼저 블록 제목과 예시를 읽고 실제 코드가 그 설명을 어떻게 구현하는지 따라가세요.

## 추천 순서

| 단계 | 파일 | 스스로 확인할 질문 |
|---|---|---|
| 실행과 설정 | `shopscope/__main__.py`, `cli.py`, `config.py` | 명령은 어느 함수를 호출하고 경로는 언제 결정될까? |
| 입력 만들기 | `generate.py`, `source.py` | 주문일·발생 시각·수신 날짜가 왜 다를까? |
| 수집 | `collect.py` | 페이지 순회 종료와 파일 무결성을 어떻게 확인할까? |
| 품질과 DB | `quality.py`, `db.py`, `sql/001_schema.sql` | 행 검증과 참조/합계 검증은 무엇이 다를까? |
| 핵심 적재 | `pipeline.py` | 배치 ID와 실행 ID, 중복과 ID 충돌은 어떻게 다를까? |
| 집계 | `sql/002_marts.sql`, `sql/003_analysis.sql` | 자식 집계를 먼저 하는 이유와 30분 세션 경계는? |
| 실패 검증 | `tests/` | 커밋 직전 실패하면 무엇이 남고 무엇이 취소될까? |
| 실행 자동화 | `demo.py`, `dags/commerce_daily.py` | 함수 순서와 태스크 의존 관계는 어떻게 연결될까? |
| 결과 표시 | `report.py`, `dashboard.py`, `web/` | 정적 스냅샷은 언제 갱신되며 어떤 카드가 필터 대상일까? |
| 성능과 통계 | `benchmark.py`, `profile.py` | 동일 결과 확인과 측정 조건이 왜 먼저일까? |
| 검색과 저장 | `search.py`, `semantic.py`, `storage.py`, `sql_lab.py` | 정확/근사 검색, 문자/의미 벡터, 원장/캐시의 차이는? |
| 환경 구성 | `pyproject.toml`, `compose.yaml`, `Makefile`, `scripts/`, `.github/` | 설치 의존성과 실행 서비스의 역할은 무엇일까? |

Python 파일 경로가 생략된 항목은 `shopscope/` 아래입니다. 각 함수와 코드 블록 위의 주석에서 설명을 확인할 수 있습니다. SQL은 `--`, JavaScript는 `//`, CSS는 `/* */`, HTML은 `<!-- -->` 주석을 사용합니다.

## 먼저 실행할 검증

프로젝트 루트에서 `.venv/bin/python -m pytest tests/test_quality.py -q`로 DB 없이 검증 규칙부터 확인하세요. 전체 테스트는 PostgreSQL이 실행 중이고 임시 DB 생성 권한이 있어야 합니다. `.venv/bin/python -m pytest -q`는 고유한 테스트 DB를 만들며 기존 shopscope 데이터 테이블을 비우지 않습니다.

## 특히 구별할 개념

- **멱등성:** 이미 완료한 배치는 건너뛰고 같은 이벤트 내용은 중복으로 처리합니다. 같은 ID의 다른 내용은 덮어쓰지 않고 격리합니다.
- **원자성:** 적재 원장, 격리, 마트, 완료 체크포인트는 같은 DB 트랜잭션에 속합니다. raw 파일과 실행 이력은 별도 수명 주기입니다.
- **시간 기준:** 수집은 수신 날짜, 일별 마트는 주문 날짜, 현금 흐름 예제는 결제 발생 날짜를 사용합니다.
- **검색 평가:** 무작위 벡터 ANN 회수율은 상품 관련성 평가가 아닙니다. 네 개 의미 검색 예시도 일반화된 품질 측정은 아닙니다.
- **화면 데이터:** 대시보드는 저장된 결과를 보여 줍니다. 날짜/채널 필터가 모든 표와 실험 결과를 재계산하는 것은 아닙니다.

## 주석을 두지 않은 생성 파일

`data/`, `reports/`, `web/data.js`, `.venv/`, `__pycache__/`, `shopscope.egg-info/`는 입력·결과·설치 산출물입니다. JSON에는 주석 문법이 없고, 생성 파일의 설명은 재실행 때 사라질 수 있으므로 생성/소비 코드에 설명했습니다. 기존 학습 문서와 실행 결과는 보존했습니다.
